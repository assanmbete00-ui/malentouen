# 03 — Royal Heritage Design System

## Plateforme officielle de la Chefferie Traditionnelle de Malentouen

---

## 1. Objet du document

Le présent document définit les fondations du *Royal Heritage Design System, abrégé **RHDS*, de la Plateforme officielle de la Chefferie Traditionnelle de Malentouen.

Le RHDS encadre les décisions visuelles et ergonomiques communes à l’ensemble de la plateforme.

Il vise à garantir :

- une identité institutionnelle cohérente ;
- une expérience utilisateur homogène ;
- une représentation digne de la Chefferie ;
- une meilleure réutilisation des composants ;
- une évolution maîtrisée de l’interface.

Ce document ne remplace pas les composants du projet. Il formalise les principes qu’ils doivent respecter.

---

## 2. Positionnement visuel

La plateforme ne doit pas ressembler :

- à un site commercial générique ;
- à un tableau de bord administratif surchargé ;
- à une application touristique informelle ;
- à une collection de sections visuellement indépendantes.

Elle doit transmettre une identité :

- institutionnelle ;
- traditionnelle ;
- contemporaine ;
- sobre ;
- crédible ;
- chaleureuse ;
- durable.

L’interface doit représenter une institution traditionnelle dans un environnement numérique moderne, sans effacer son héritage culturel.

---

## 3. Principes directeurs

### 3.1 Dignité institutionnelle

Chaque interface doit préserver le caractère officiel de la Chefferie.

Les effets visuels excessifs, les animations décoratives inutiles et les compositions trop commerciales doivent être évités.

### 3.2 Héritage et modernité

Le design doit associer :

- les références visuelles liées à la tradition ;
- une structure numérique contemporaine ;
- une navigation claire ;
- une présentation accessible aux utilisateurs actuels.

La modernité ne doit pas remplacer l’identité traditionnelle. Elle doit lui servir de support.

### 3.3 Sobriété

Les couleurs, les ombres, les bordures et les effets doivent être utilisés avec mesure.

La hiérarchie doit principalement être construite par :

- les espacements ;
- la typographie ;
- les contrastes ;
- les proportions ;
- les alignements.

### 3.4 Cohérence

Une même fonction doit conserver une apparence et un comportement cohérents dans toute la plateforme.

Un bouton principal ne doit pas changer arbitrairement de forme ou de langage visuel d’une page à une autre.

### 3.5 Lisibilité

Le contenu institutionnel doit rester prioritaire.

Les choix graphiques ne doivent jamais réduire :

- la compréhension ;
- la lecture ;
- l’accessibilité ;
- la visibilité des actions importantes.
