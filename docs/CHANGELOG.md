# CHANGELOG.md

# Journal des évolutions

## Plateforme officielle de la Chefferie Traditionnelle de Malentouen

---

Ce document retrace les évolutions majeures du projet.

Il ne liste pas chaque modification du code.

Il conserve uniquement les décisions importantes ayant un impact sur :

- l'architecture ;
- le produit ;
- le RHDS ;
- les composants ;
- les conventions de développement ;
- l'expérience utilisateur.

---

# Format

Chaque évolution doit contenir :

- la date ;
- le domaine concerné ;
- un résumé ;
- l'impact sur le projet.

# Règle

Le CHANGELOG décrit uniquement les évolutions importantes.

Les corrections mineures ou les ajustements internes ne sont pas enregistrés.

Il constitue la mémoire officielle des grandes décisions prises pendant la vie du projet.
